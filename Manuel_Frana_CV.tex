{\small
Senior QA Engineer with 5+ years on the core backend framework an enterprise SaaS platform is
built on --- database access, caching and metrics --- depended on by 40 product teams. The work
is a mix of proactive and reactive: reviewing backend defects escalated by client-facing teams
and tracing, triaging and analysing them through Grafana, Kibana and Prometheus metrics,
alongside standard QA for new features (test planning, execution and coverage). When a gap in
coverage or reliability turns up I own it end to end --- technical specification, acceptance
criteria and the implementation in platform code --- always shipped through the team's normal
review and release process. Because the framework is proprietary, much of the testing and
release infrastructure is built in-house. Strong in test automation, API and integration
testing, CI/CD quality gates, progressive rollouts and root cause analysis across PHP, Python
and JavaScript backed by MySQL and Redis.
